# Reels 白板字體（2026-11-12 定案）

| 用途 | 檔案 | 來源 | 授權 |
|---|---|---|---|
| 白板數字、英文 | PatrickHand-Regular.ttf | Patrick Hand（npm @fontsource/patrick-hand，latin 子集轉 ttf） | SIL Open Font License 1.1 |
| 白板中文 | XiaolaiSC-Regular.ttf | 小賴字體 Xiaolai（npm @proj-airi/font-xiaolai） | SIL Open Font License 1.1 |

規則：白板上所有字（系列名、No.、題目、算式）都用這組；中文用小賴，數字／英文／符號用 Patrick Hand（字級放大 1.1 倍對齊中文）。
字幕仍用 Noto Sans CJK Black 白字黑邊，不用手寫字。
